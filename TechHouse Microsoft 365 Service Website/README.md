# 💼 TechHouse Microsoft 365 Services Website

A responsive business website developed to showcase **TechHouse's Microsoft 365 services, solutions, and consultation offerings**. This project was created as a practice exercise to strengthen my frontend development skills by recreating a professional corporate website design.

---

## 📌 Project Overview

The TechHouse Microsoft 365 Services Website is designed to provide businesses with information about Microsoft 365 solutions and the services offered by TechHouse. The website focuses on delivering a clean user experience while effectively presenting service details, benefits, and consultation options.

This project allowed me to practice implementing real-world business website layouts while improving my proficiency in modern web technologies.
