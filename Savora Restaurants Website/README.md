# Savora Restaurant Website 🍽️

A modern and fully responsive **Restaurant Website** built using **HTML, CSS, Bootstrap, and Font Awesome**.
This project showcases a stylish restaurant landing page with interactive UI components, beautiful layouts, responsive sections, menu categories, testimonials, pricing plans, and elegant animations.

---

## 📌 Features

* Modern & Responsive Design
* Interactive Navigation Bar
* Multi-level Dropdown Menu
* Hero Section with CTA Buttons
* Restaurant Menu Section
* Gallery Section
* Pricing Plans
* Testimonials Section
* Hover Animations & Effects
* Smooth Card & Image Transitions
* Mobile-Friendly Layout
* Elegant UI Design

---
