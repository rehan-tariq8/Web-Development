# 🍔 Feane - Restaurant Website

A modern and responsive restaurant website built using **HTML**, **CSS**, and **Bootstrap 5**.
This project was created as a frontend development practice project to improve UI design, responsive layouts, and component structuring skills.

---

## 🚀 Features

* Responsive Navigation Bar
* Hero Section with Call-to-Action
* Food Menu Cards
* Discount Offer Sections
* About Us Section
* Table Booking Form
* Customer Testimonials
* Footer with Social Links
* Embedded Google Map
* Fully Responsive Design using Bootstrap

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* Bootstrap 5
* Font Awesome
* Google Fonts
